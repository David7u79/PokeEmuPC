# Controller artwork credits

The controller illustrations in `assets/controllers` are original PocketPartner
artwork. Their chassis, screen, control, and decorative shapes were drawn for
this repository; no third-party SVG paths, files, fragments, or assets were
incorporated.

The RetroPie **carbon** theme by Rookervik was consulted locally only to measure
general console proportions while creating the artwork. Carbon is licensed
CC-BY-NC-SA. Nothing from that theme has been copied into this repository.
